# POS: 51 | TYPE: paragraph
1.1  项目背景

# POS: 52 | TYPE: paragraph
近年来，随着居民风险保障意识提升，公司人寿、健康及意外险业务规模持续扩大，年理赔案件量已突破数百万件。与之相对，传统理赔作业高度依赖纸质单证流转、人工录入与线下审批，暴露出三方面突出问题：一是处理周期长，常规案件平均结案时长约  5  个工作日，客户投诉中逾三成与时效相关；二是材料传递易遗失、易篡改，单证真实性核验缺乏系统化手段；三是反欺诈识别滞后，高风险案件往往事后才发现。与此同时，监管对保险服务透明度、理赔时效披露及消费者权益保护提出了更高要求。为落实公司 " 数字化 、智能化、以客户为 中心 " 的战略，特提出建设智能保险理赔服务系统，通过多渠道报案、 OCR  单证识别、规则引擎自动核赔与人工复核相结合，全面提升作业效率、风控能力与客户体验。

# POS: 53 | TYPE: paragraph
本说明书作为项目建设的第一份用户侧需求文件，旨在对齐业务方、数据治理方与实施方的认知，为后续概要设计、详细设计与测试提供基线。
