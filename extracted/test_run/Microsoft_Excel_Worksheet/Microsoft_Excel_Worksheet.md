| 【项目背景】
随着公司业务的快速扩张，传统的人工+Excel模式的供应链管理已无法满足日均10万+订单的处理需求。现有系统存在库存数据滞后（T+1更新）、采购决策依赖经验判断、订单履约周期长（平均72小时）等核心痛点。

【项目目标】
构建一套覆盖采购、库存、预测、履约、分析五大核心域的智能供应链管理平台。系统引入机器学习算法进行需求预测，结合动态安全库存策略，目标将库存周转率提升至8.0次/年，缺货率降低至2%以下，订单履约周期缩短至24小时以内。
